# 고려대 제시문 스토어 🍭

2022~2026학년도 고려대학교 계열적합전형 기출 20세트와 공통 사고 훈련을 담은 캔디 자판기 형태의 수업용 HTML입니다.

## 사용 방법

`index.html`을 다운로드한 뒤 브라우저로 열거나, 정적 웹 호스팅 서비스에 배포합니다. 별도 설치나 빌드가 필요하지 않습니다.

- 인문·자연·공통 선택, 학년도 필터, 채널 선택과 캔디 뽑기
- 대학 공식 제시문·문항 및 공식 예시답안 이미지
- 교사용 풀이 안내, 지도 포인트, 5개년 출제 경향
- 학생용 핵심어·답안 숨김 (접근 권한 제한 기능은 아님)
- 키워드 추출 → 관계표 → 답변 메모 → 설명 → 수정 → 실전 연습지
- 브라우저 자동 저장, JSON 내보내기·불러오기, 인쇄/PDF
- 준비 21분·면접 7분 타이머

## 기록 보관

학생 입력은 현재 기기의 브라우저에만 저장되며 서버로 전송되지 않습니다. 브라우저 데이터 삭제나 기기 변경에 대비하여 JSON 내보내기를 사용하세요.

## 자료 출처와 구분

고려대학교 입학처의 2022~2026학년도 선행학습 영향평가 보고서를 기반으로 합니다. 공식 원문과 제작한 지도용 해설을 구분해 수록했습니다. 공통 채널과 연습지는 자체 제작한 학습 자료입니다.

대학 원문 및 인용된 제시문의 권리는 각 권리자에게 있습니다. 이 저장소는 고려대학교의 공식 서비스가 아니며, 예시답안과 지도용 안내는 합격이나 특정 점수를 보장하지 않습니다.

Google Fonts를 이용할 수 없는 환경에서도 기본 글꼴로 작동합니다. 기출 이미지와 앱 코드는 HTML 안에 포함되어 있습니다.
